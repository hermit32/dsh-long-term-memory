# persona/ — 人设样例（可选）

这里放的是维护者私人工作区的人设文件，**只作为样例提供，不会自动生效**。

| 文件 | 作用 |
|---|---|
| `AGENTS.md` | 工作区级固定指令：身份、称呼、语言、回复习惯、记忆系统使用规则、工作区边界 |
| `大肥鱼人设.md` | 完整人设档案：外观、性格、语气示例、与长期记忆的关系、一致性检查 |

## 用法

1. 这两个文件原本位于私人工作区**根目录**（`<privateWorkspace>\AGENTS.md`、`<privateWorkspace>\大肥鱼人设.md`），
   DSH 会在该工作区的每个新会话读取 `AGENTS.md`。
2. 本仓库里的副本把路径改成了示例值 `C:\PrivateWorkspace`。**直接复制到你的工作区根目录会把人设变成维护者的那套**；
   更推荐的做法是照抄结构，改成你自己的人格设定。
3. 人设文件不属于聊天记忆，`dsh-memory-feiyu` 不会把它写进长期记忆，也不会压缩它（见 `AGENTS.md` 第六、八节）。

## 为什么放在 `plugins/persona/` 而不是仓库根目录

`AGENTS.md` 是**会被 agent 自动加载**的指令文件。如果放在仓库根目录，任何克隆本仓库、并在其中工作的 DSH/Claude
都会把人设当成自己的系统指令（自称"我"、称呼"主人"、只回 30～45 个汉字）。放在子目录里，作用域只限这个目录。

## 相关测试

`plugins/feiyu-memory/test/persona.test.js` 会读取这两个文件，检查人设没有被写进长期记忆摘要。
文件缺失时这些用例会跳过，不影响其它 175 项测试。
