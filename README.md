# DeepSeek Harness Private AI Workspace

基于 DeepSeek Harness 构建的私人 AI 工作区扩展方案。

## 项目目标

让一个 AI 助手同时拥有：

- 自定义人格与多个独立会话
- 可持续积累的长期记忆
- 自动整理、来源追溯与记忆管理
- 微信与桌面交互
- 多工作区隔离和单向消息通知
- 会话归档、恢复与删除

## 复现思路

1. 安装兼容版本的 DeepSeek Harness。
2. 创建私人工作区、工作区 A、工作区 B。
3. 为私人工作区配置 `AGENTS.local.md`。
4. 基于 `dsh-memory` 的本地分支实现独立长期记忆及整理机制。
5. 接入记忆管理控制台与会话管理插件。
6. 配置微信接入和跨工作区单向通知。
7. 验证工作区权限隔离、记忆召回与会话删除行为。

## 当前状态

本仓库目前主要分享架构设计与复现思路，尚不是一键部署工具。

跨会话统一累计 20 轮、新建会话触发全工作区整理属于计划中的增强功能，需完成实施验证。
